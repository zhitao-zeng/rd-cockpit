# Contributing

1. Keep examples anonymous and portable.
2. Never commit generated reports, ledgers, Session data, credentials, private
   network addresses, or absolute machine paths.
3. Run the backend and frontend test suites.
4. Run `./scripts/privacy-check.sh --history` before proposing a release.
5. Preserve the distinction between observed, reported, inferred, and
   confirmed information.

By contributing, you agree that your contribution is licensed under the MIT
license in this repository.
